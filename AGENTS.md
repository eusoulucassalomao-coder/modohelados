# Project instructions

- This repository is deployed through GitHub and Vercel. Keep commits on the default branch buildable; never rewrite published history.
- Supabase is the application backend. The project ref is `zlbyzmfzcnqdunbgjedp` and the project URL is `https://zlbyzmfzcnqdunbgjedp.supabase.co`.
- Database schema changes must be represented in `supabase/migrations/` and applied to the linked Supabase project. Keep migrations idempotent where practical.
- Do not commit service-role keys, database passwords, personal access tokens, or other secrets. Browser code may only use the Supabase URL and publishable/anon key.
- Vercel environment variables: `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`.
- Menu source data is bilingual and lives in `src/data/menu.json`. Shared translations live in `src/lib/i18n.ts`.
- `src/routeTree.gen.ts` is generated by TanStack Router. Never edit it manually.
- Inspect the existing implementation before changing infrastructure, routes, or database structures. Prefer additive changes and preserve existing customer-facing behavior.
